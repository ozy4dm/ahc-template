# 参加者による判断の記録

大会ごとの解法の採用・棄却、実験条件、採用基準など、**参加者自身が行った解法上の判断**をここに記録します。AI は参加者から伝えられた判断を整理・転記できますが、判断内容を補ったり提案したりしません。

| 日付 | 対象 | 参加者の判断 | 事前に定めた基準・根拠 | 関連する実験 | 記録した人 |
|---|---|---|---|---|---|

判断の根拠が実験結果なら、対応する `docs/experiments/EXP-*.md` と結果ファイルを参照します。変更後に理由を推測して書き足さず、不明な点は参加者に確認します。この台帳と Git 履歴は生成 AI の対話・作業ログの代わりにはなりません。
