参加者が指定した実装内容: $ARGUMENTS

1. `AGENTS.md` と対象コード、`docs/solutions.md` を確認する。
2. アルゴリズム、評価関数、パラメータ、停止条件、入出力など実装に必要な解法仕様が不足していれば、独自に補わず質問する。候補や推奨案は出さない。
3. 指定された仕様だけを実装する。不具合修正では既存の解法を変えない。評価済みの版の履歴を保つ。
4. 仕様との一致に必要な最小限のテストを行い、変更内容と確認結果を報告する。スコアを見た後に改善方針を考案しない。
