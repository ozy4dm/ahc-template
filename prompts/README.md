# Claude Code に渡すプロンプト例

リポジトリのルートで Claude Code を起動し、最初に `/context` で `CLAUDE.md` とそこから読み込まれる `AGENTS.md` を確認してください。開催時点の公式な AI 利用ルールが変わった場合は、作業前に `AGENTS.md` と以下の文面の整合性を確認します。以下の `［...］` は参加者自身が記入します。解法上の判断を Claude に委ねないため、空欄は Claude に決めさせず質問させてください。

## 依頼文を送る前の確認

```text
/ahc-rule-check ［この後 Claude Code に依頼したい文面をそのまま貼る］
```

これは依頼の事前点検だけを行います。判定で「禁止事項に該当する依頼」と出ても、その文面を書いたことだけで直ちに参加者のルール違反と断定するものではありません。判定が曖昧な場合は、人間が仕様や意図を明確にしてください。

## 大会の準備

```text
/ahc-setup 対象大会: ［大会名・URL］。公式AI利用ルール: ［確認したURLまたは全文］。問題文: ［手動で保存した local/ 内の場所］。使用言語: ［言語］。公式ツール: ［手動で保存した tools/ 内の場所］。採点方法と制限時間: ［仕様］。不足する仕様は候補を示さず質問してください。解法は作らないでください。
```

## 人間が決めた解法の実装

```text
/ahc-implement 対象の版: ［ID］。入力・出力仕様: ［仕様］。実装するアルゴリズムと処理順序: ［具体的な仕様］。評価関数・パラメータ・停止条件: ［具体的な仕様］。この仕様どおりに実装し、仕様との一致を確認してください。解法上の仕様が不足していれば、候補を挙げず質問してください。
```

## 解法を変えない不具合修正

```text
/ahc-implement 対象の版: ［ID］。期待する動作: ［仕様］。実際の動作と再現ケース: ［事実・ケースID］。指定済みの解法は変えず、実装との不一致を調査・修正してください。変更後は再現ケースと関連テストで確認し、原因と変更点を報告してください。
```

## 指定済みの比較実験

```text
/ahc-experiment 実験ID: ［EXP-xxx］。baseline: ［版ID］。candidate: ［版ID］。ケース集合: ［manifestまたは具体的な一覧］。seed・反復回数: ［値］。1ケースの時間制限: ［値］。スコアの向きと集計方法: ［仕様］。事前の採用基準: ［参加者が決めた条件］。条件を記録してから実行し、結果を機械的に集計・報告した時点で止まってください。改善案は考案しないでください。
```

スキルを使わず通常のメッセージとして入力する場合も、`/ahc-...` を除いた同じ内容を使えます。
